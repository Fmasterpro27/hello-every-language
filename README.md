# hello-every-language 👋🌍

A fun collection of **"Hello, World!"** programs written in different programming languages, frameworks, and technologies.

This project was created just for fun. The goal is to collect as many **Hello, World!** examples as possible in one place.

## 🌐 Currently Included

- Python
- C
- C++
- C#
- Rust
- Lua
- JavaScript
  - Vanilla JavaScript
  - React
  - TypeScript

More languages and frameworks will be added over time.

## 🤝 Contributing

Contributions are welcome!

If you know a programming language or framework that isn't included yet, feel free to open a Pull Request. Please keep examples simple and focused on a basic **Hello, World!** program.

## 📄 Disclaimer

This repository is a fun community project. It is **not** intended to be a complete programming tutorial or reference. Its purpose is simply to gather "Hello, World!" examples from as many languages and technologies as possible.
